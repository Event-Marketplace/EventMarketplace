# Event Marketplace

Event Marketplace to platforma umożliwiająca organizację, zarządzanie oraz udział w wydarzeniach. System składa się z backendu opartego o .NET Web API oraz frontendu zbudowanego w Next.js.
Projekt został stworzony jako część portfolio w celu zaprezentowania umiejętności projektowania systemów backendowych oraz aplikacji fullstackowych.
Projekt w aktywnym rozwoju. Core funkcjonalności są zaimplementowane, kolejne moduły są dodawane iteracyjnie.
